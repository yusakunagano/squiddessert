# 📘 えいたんご — 英単語学習アプリ

スマホ・タブレット・PC のブラウザで動く英単語学習アプリです（React + Vite + TypeScript）。

## できること

| 機能 | 内容 |
| --- | --- |
| 単語の登録 | 「単語帳 → ＋単語を登録」で英単語・意味・例文（いくつでも）を登録。「自動入力」で意味と例文を自動で作成 |
| 音声 | 🔊 ボタンで単語・例文を読み上げ（ブラウザの音声合成）。速さと声は設定で変更可 |
| タップで翻訳 | 単語をタップすると日本語訳、例文をタップするとその訳を表示 |
| 複数の例文 | 1つの単語に複数の例文。英検単語には最初から2つずつ収録 |
| 英検テスト | 5級〜1級を選ぶと単語が順番に出題（前回の続きから出題） |
| 手書き解答 | 4本線のノートに指・ペンでアルファベットを書いて解答 |
| できなかった一覧 | 結果画面でチェックした単語を「できなかった一覧」に保存 |
| 再テスト | 一覧の ☆ をタップ（または一括）で再テスト項目に。再テストだけのテストも可能 |
| AIと会話 | 再テスト項目の単語を中心に AI（Claude）と英会話。使えた単語に ✅、音声入力・読み上げ・日本語訳つき |

## 公開URL

https://yusakunagano.github.io/squiddessert/eitango/

スマホで開いて「ホーム画面に追加」するとアプリのように使えます。

## 開発と公開

```bash
cd eitango-app
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # ../eitango/ に公開用ファイルを出力
```

`npm run build` で `eitango/` フォルダが更新されます。それを main ブランチに入れると GitHub Pages に反映されます（nine-game と同じ仕組み）。

## AI 機能（任意）

「設定」で **Gemini**（Google AI Studio で無料のAPIキーを作れる・回数制限あり）か **Claude** を選べます。

「設定」で Claude の API キー（[Anthropic Console](https://console.anthropic.com/) で発行）を入れると、次の機能が有効になります。

- 手書き文字の読み取りによる自動採点（キーがない場合は答えを見て自分で ○× をつけます）
- 意味・例文の自動作成（キーがない場合は無料の辞書 API／翻訳 API で自動入力します）
- 再テスト単語を中心にした AI との英会話

API キーはブラウザの localStorage にだけ保存され、ブラウザから直接 Anthropic API に送られます。
自分専用の端末で使う前提の作りです。多人数に公開する場合は、キーをサーバー側に置くプロキシを用意してください。

## データ

単語・テスト結果・会話はブラウザの localStorage に保存されます。「設定 → バックアップ」で JSON に書き出し・復元できます。

## 単語リスト

| 級 | 5級 | 4級 | 3級 | 準2級 | 2級 | 準1級 | 1級 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 収録数 | 457 | 275 | 716 | 899 | 1,393（＋熟語274） | 1,223 | 1,212 |

すべての単語に意味と例文2つ（英文・和訳）が付いています。

- `src/data/eiken.ts` … 各級の基本リスト
- `src/data/words/*.ts` … 5級・4級・3級・準2級・準1級・1級の単語（ファイル名の先頭が級。`words/index.ts` は自動生成）
- `src/data/eiken2-*.ts` … 2級の単語（動詞・名詞・形容詞/副詞）
- `src/data/eiken2-idioms1.ts` / `eiken2-idioms2.ts` … 2級の熟語（「2級熟語」として別に出題）。`~` は目的語などが入る場所で、テストでは書かなくてよい

`[単語, 意味, 例文1, 訳1, 例文2, 訳2]` の行を追加するだけで、単語帳とテストに反映されます。同じ単語が複数の級にある場合は下の級のほうだけが使われます。
