# squiddessert

## AI職業サポート

10 問または 20 問の質問に答えると、Google Gemini（`gemini-flash-lite-latest`）があなたの性格と向いている職業を診断します。
10 問答えたところで「ここで結果を見る」か「あと 10 問答えて詳しく診断する」かを選べます。10 問で見た結果からも、残りの 10 問に答えて診断し直せます。
診断には 30 秒〜1 分ほどかかり、待っている間はミニゲーム「コバエたたき」で遊べます。
結果には、あなたの性格、いちばん向いている職業（名刺風のカード）とその職業の年収の目安、日本で就いている人の数、業界の楽しいこと・大変なこと、これから訪れる変化、代表的な会社 20 社、役立つ資格（最大 10 件）、仕事タイプ、傾向（創造力・協調性・分析力・行動力）、ほかに向いている職業 2 つ、向いていないかもしれない職業 2 つ、一緒に働くと相性の良い職業の人・ぶつかりやすい職業の人（うまく付き合うコツ付き）、結婚するなら相性の良い職業の人、強み、生活する上で気を付けること（ひとつながりの文章）、最初の一歩のアドバイスが表示されます。
結果には、向いている職業の求人をリクナビNEXT（転職）・リクナビ（新卒）で探すリンク（Google のサイト内検索）も表示します。
結果の最後には、診断された職業について AI に質問できるチャットがあります（1 回の診断につき 3 回まで）。「結果をすべてコピー」で結果・回答・チャットをまとめてコピーでき、ChatGPT・Gemini・Claude などに貼り付けて相談を続けられます。

- `job/index.html` … 診断ページ（静的 HTML）
- `api/diagnose.js` … 診断を行うサーバーレス関数（Vercel 形式、Gemini API を使用）
- `api/chat.js` … 職業についてのチャットに答えるサーバーレス関数
- `api/_shared.js` … 上の 2 つで共通の処理（Gemini の設定、CORS、エラー処理）

### API キーの発行

1. [Google AI Studio](https://aistudio.google.com/apikey) に Google アカウントでログインし、API キーを作成
2. キーは GitHub に書き込まず、下の手順で Vercel の環境変数に設定

Gemini API には無料枠があります（回数の上限あり）。無料枠では送信内容が Google のサービス改善に使われる場合があるため、公開前に最新の料金と利用規約を確認してください。

### デプロイ（Vercel）

1. このリポジトリを Vercel にインポート
2. 環境変数 `GEMINI_API_KEY` を設定
3. デプロイ後 `https://<your-app>.vercel.app/job/` を開く

API キーはサーバー側だけで使われ、ブラウザには公開されません。利用者が API キーを入力する必要はありません。

GitHub Pages の `job/` ページから使う場合は、`job/index.html` の `API_ORIGIN` に Vercel の URL（`https://squiddessert.vercel.app`）を設定済みです。
API は `https://yusakunagano.github.io` からの呼び出しを許可しています（`api/_shared.js` の `ALLOWED_ORIGINS`）。

### ローカルで動かす

```bash
npm install
GEMINI_API_KEY=... npx vercel dev
# → http://localhost:3000/job/
```

## 永野AI 比較

同じ質問を Gemini Flash と Gemma 4 に投げ、どちらが「永野らしい」答えかをブラインド（どちらのモデルか伏せた状態）で選ぶ実験ページです。選んだ結果はブラウザに集計されます。

- `nagano-ai/index.html` … 比較ページ（静的 HTML）。永野さんの情報（口調・価値観・回答例）はページの入力欄に書き、ブラウザにだけ保存されます（リポジトリには置かない）。
- `api/nagano-compare.js` … 2 つのモデルを並列で呼ぶ関数。どちらにも同じ 1 通のメッセージ（永野さんの情報＋質問）を渡します。
- API キーは職業サポートと同じ `GEMINI_API_KEY`（Google AI Studio のキー）を使います。
- モデル名は環境変数 `FLASH_MODEL`（既定 `gemini-flash-latest`）と `GEMMA_MODEL`（既定 `gemma-4-31b-it`）で変えられます。Gemma の名前が違って見つからないときは、ページに使えるモデル名の一覧が出ます。

## AIサポート（決済アプリのプロトタイプ）

`pay-ai-support/` のホームのAIアシスタントで「お得な情報を知りたい」を押したときだけ、`api/pay-assistant.js` 経由で Gemini に問い合わせます（それ以外の質問はページ内のルールで回答）。
APIキーは職業サポートと同じ `GEMINI_API_KEY`（Vercel の環境変数）を使います。

- AI に渡すのは、ページに表示している公開情報と、利用者が許可した項目（残高・ポイント／利用明細／カード請求）だけです。
- AI は答えるほか、送金・利用履歴・口座登録・利用サービスの画面を開くこと、情報提供の許可を求めることができます（送金そのものは行いません）。
- API に接続できないときは、ページ内の簡易ルールで答えます。

### お得な情報：キャンペーンの事前読み取り

ホームのAIで「お得な情報を知りたい」を押したときは、キャンペーンページを**事前に読んで保存したデータ**で案内します（チャットのときはページを読みに行きません）。

- `scripts/crawl-campaigns.mjs` … キャンペーンページの特集一覧（タイトル・種別・エントリー要否・期間・リンク先）と、各リンク先の詳細（還元・上限・対象・エントリー方法・注意）を Gemini で読み、`pay-ai-support/data/campaigns.json` に保存します。
- `.github/workflows/crawl-campaigns.yml` … 上のスクリプトを毎日 1 回（日本時間 5:17）実行し、内容が変わったときだけ main にコミットします。手動で実行するときは GitHub の「Actions」→「キャンペーンの事前読み取り」→「Run workflow」。
- `api/_campaigns.js` … ページの読み取り（スクリプトと API で共通）。同じサイト内のリンクだけを読み、ページの取得に成功したと確認できたときだけ内容を採用します。
- `api/pay-assistant.js` … チャットのたびに保存データを取り込み、**一覧（タイトルなど）は常に、詳細は利用者の話に合う上位 5 件だけ**を AI に渡します。保存データがないときは、その場でページを読み、それも読めなければ画面の固定の概要で答えます。
  特集を紹介するときは、AI が選んだ特集の id を、保存データにある本物の URL（同じサイト内のものだけ）に置き換えて、返事の下にリンクとして表示します（AI に URL は書かせません）。

セットアップ：GitHub のリポジトリの Settings → Secrets and variables → Actions に `GEMINI_API_KEY`（Vercel に設定しているものと同じキー）を登録します。

```bash
# 手元で試すとき
GEMINI_API_KEY=... node scripts/crawl-campaigns.mjs
```

### 銀行口座の登録（`pay-ai-support/register.html`、プロトタイプ）

実際のアプリに近い 16〜18 ステップ、5 つの段階（準備 → 口座 → 本人確認 → 認証 → 設定）の流れです。流れの本体は `register.js` です。

- **準備**：登録の流れと準備するもの／規約への同意／SMS による電話番号の確認
- **口座**：金融機関の検索（かな・カタカナ・種別）／登録方法の選択（金融機関のサイトで承認 or キャッシュカードの暗証番号。金融機関ごとに選べる方法が違う）／預金種別・支店・口座番号／口座名義と生年月日
- **本人確認**：書類の選択（マイナンバーカードは IC 読み取り or 撮影で分岐。書類ごとに撮影する面が違う）／顔の撮影／読み取り内容の確認／審査待ち
- **認証**：金融機関のサイトにログイン → ワンタイムパスワード → 提供情報の承認、または暗証番号の入力
- **設定**：チャージ上限・オートチャージ／登録内容の確認（各項目を修正できる）／完了
- つまずく場面：メンテナンス中の金融機関、当座預金、名義の不一致、18 歳未満、SMS コードの誤り、書類・顔の撮影失敗、IC 読み取り失敗、ログイン・暗証番号のロック、連携の拒否（登録方法の選択に戻る）
- 途中保存：「あとで続ける」で中断でき、同じタブなら「続きから再開」できる（暗証番号・パスワード・認証コードは保存しない）
- AIサポートは画面ごとに候補と答えが変わり、エラーが出ているときはその説明から始める

画面内の「デモ：」は動作確認用の値です（SMS コード `123456`、ネットバンキングのパスワード `bank1234`、ワンタイムパスワード `654321`、暗証番号 `1234`、アカウントの氏名「ヤマダ タロウ」）。
