# オンラインランキングの準備（Firebase）

ナインゲームのランキングは、Google の **Firebase** を使っています。

- **Authentication（匿名ログイン）**: プレイヤーには見えない仕組みです。ブラウザごとに見えない ID を割り当てて、他人の記録を書き換えられないようにします。プレイヤーはアカウントを作らず、名前を入れるだけで登録できます。
- **Firestore**: スコアの保存（週間・総合ランキング）

無料の Spark プランで足ります。クレジットカードの登録はいりません。

設定が終わるまでは、ゲーム画面に「オンラインランキングは準備中です」と表示されます。ゲーム自体はふつうに遊べます。

---

## 1. Firebase プロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログインします。
2. 「**プロジェクトを作成**」を押して、名前を入れます（例: `nine-game`）。
3. Google アナリティクスは「**無効**」で大丈夫です。「プロジェクトを作成」を押します。

## 2. 匿名ログインを有効にする

1. 左のメニューの「**構築 → Authentication**」を開き、「**始める**」を押します。
2. 「Sign-in method」タブで「**匿名**」（Anonymous）を選びます。
3. 「**有効にする**」をオンにして「**保存**」を押します。

## 3. スコアの保存場所（Firestore）を作る

1. 左のメニューの「**構築 → Firestore Database**」を開き、「**データベースの作成**」を押します。
2. ロケーションは「**asia-northeast1（東京）**」を選びます（あとから変えられません）。
3. 「**本番環境モード**」を選んで作成します。
4. できたら「**ルール**」タブを開きます。中身を全部消して、このフォルダの `firestore.rules` の中身を貼り付け、「**公開**」を押します。

## 4. Web アプリを登録して、設定をゲームに入れる

1. 左上の歯車 → 「**プロジェクトの設定**」を開きます。
2. 下のほうの「マイアプリ」で **`</>`（ウェブ）** のアイコンを押します。
3. アプリのニックネーム（例: `nine-game-web`）を入れて「アプリを登録」を押します。Hosting のチェックは不要です。
4. 表示される `const firebaseConfig = { ... };` の **`{` から `}` まで**をコピーします。
5. 次のどちらかで、ゲームに設定を入れます。
   - **Claude に貼り付けて渡す**（いちばん簡単）。私が `nine-game/firebase-config.js` に入れてプルリクエストを作ります。
   - 自分で入れる場合: GitHub で `nine-game/firebase-config.js` を開いて鉛筆アイコンで編集し、最後の行の `null` をコピーした `{ ... }` に置き換えて保存します。

> この設定（apiKey など）は、Web ページに書いて公開しても大丈夫なものです。データは手順 3 のルールで守っています。

---

## 知っておいてほしいこと

- **スコアの不正**: スコアはプレイヤーの端末で計算しています。そのため、知識のある人がわざと偽のスコアを送ることは完全には防げません。ルールで「100万点まで」に制限しています。おかしな記録は、Firestore の画面から行ごと削除できます。
- **週間ランキング**: 今日をふくむ直近7日間（日本時間）の記録です。毎日0時に1日ずつずれていきます。`plays` の記録を、登録日時で絞り込んで表示しています。
- **終了した仕組み**: 月曜はじまりの週間ランキング（`weeks/`）、デイリーランキング（`days/`）、日本ランカー（`players/`）は今は使っていません。古いページを開いたままの人が登録しても失敗しないように、ルールだけ残しています。前の記録はそのまま残っています。
- **名前**: 誰でも好きな名前を付けられます。不適切な名前は、Firestore の画面で `plays` から、その行を削除してください（前の仕組みの記録は `weeks/`・`days/`・`players/` にも残っています）。
- **ゲームセンター式**: 遊ぶたびに、その回のスコアが 1 行ずつ登録されます。同じ人が何行もランキングに入ることがあります。自分の記録は名前が緑色で表示され、今登録した記録は枠で目立ちます。
- **プライバシーポリシー**: ランキングのために「プレイヤーが入力した名前とスコア」を保存するようになります。プライバシーポリシーにその旨を書き足しておくのが安全です。
